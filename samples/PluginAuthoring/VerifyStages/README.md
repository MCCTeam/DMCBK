# Verify an incremental plugin stage

Pass a package folder and its tutorial stage number, from 1 to 4.

```sh
dotnet run --project samples/PluginAuthoring/VerifyStages -- samples/PluginAuthoring/TutorialStages/Stage04 4
```

The program loads the actual source package. Later stages also check the session variable, saved storage, and localized command.

Use an absolute folder path to check your own implementation at the matching chapter.

A failed check gives a nonzero process exit status. The fake server exchanges protocol frames in memory and opens no socket.
